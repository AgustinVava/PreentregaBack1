# MobileNest 

## Bienvenidos a nuestra ultima entrega de Backend 🚀
Estamos emocionados por presentarles nuestro proyecto final conl Backend. Hemos desarrollado un e-commerce para celulares de toda gama o marca; incluyendo accesorios, laptops, tablets, etc. Es un pequeño nido dogital para que puedas conseguir siempre tu telefono deseado.

La forma de uso de este proyecto es yendo a la rama llamada finalchallenge en donde podras crear tu usuario, ver los productos e incluso visualizar en tiempo real los ultimos usuarios que se han registrado.
